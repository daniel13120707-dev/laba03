\# Lab03 — Токенизация текста на C#



\## Описание

Лабораторная работа: анализ требований, выделение классов, разделение ответственностей.

Программа разбивает текст на токены (слова, знаки препинания, предложения) и выполняет аналитические операции.



\## Возможности

\- Два парсера: `CharByCharParser` и `RegexParser`

\- Поддержка русского и английского языков

\- Сортировка предложений по количеству слов и длине

\- Поиск слов заданной длины в вопросительных предложениях

\- Удаление слов заданной длины, начинающихся с согласной

\- Замена слов заданной длины на подстроку

\- Удаление стоп-слов (RU/EN)

\- Экспорт в XML (`System.Xml.Serialization`)



\## Структура проекта

TextTokenizer/

├── Models/        # Token, Word, Punctuation, Sentence, Text

├── Parsers/       # ITextParser, CharByCharParser, RegexParser

└── Services/      # StopWordProvider, TextAnalyzer, TextXmlSerializer
